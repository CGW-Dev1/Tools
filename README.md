# Tools

这个仓库用于集中存放个人小工具项目，后续新增项目时可以在根目录继续创建独立文件夹。

## 项目列表

- [DevToolbox](DevToolbox/)：Windows 本地离线开发工具箱，包含 JSON、Cron、Base64、加密哈希、正则、文档对比、PDM 查看等功能。
- [MicrosoftMailFetcher](MicrosoftMailFetcher/)：微软 Outlook/Hotmail 邮箱批量取件工具，支持 Graph/IMAP、验证码简洁模式、账号导入导出。
